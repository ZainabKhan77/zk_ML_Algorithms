# zk_ML_Algorithms
Machine Learning Algorithms implemented in Python

## Files

1. **logistic_regression**  
   - Uses the Iris dataset  
   - Performs multi-class classification using Logistic Regression  
   - Prints accuracy

2. **decision_tree**  
   - Uses Titanic dataset  
   - Predicts survival using Decision Tree  
   - Handles basic preprocessing

3. **KNN_ondigital**  
   - Uses Digits dataset  
   - Applies K-Nearest Neighbors  
   - Outputs classification report

4. **SVM_onbreastcancerdataset**  
   - Uses Breast Cancer dataset  
   - Uses Support Vector Machine to classify  
   - Prints accuracy

5. **RandomForest_onWineDataset**  
   - Uses Wine dataset  
   - Trains Random Forest Classifier  
   - Evaluates using accuracy score
